# LangGraph 项目

这是一个基于 LangGraph 的简单示例项目，演示了如何创建和运行状态图工作流。

## 项目结构

```
langgraph-project/
├── app.py          # 主应用文件
└── README.md       # 项目说明
```

## 功能特性

- ✅ 状态管理：使用 TypedDict 定义工作流状态
- ✅ 节点系统：实现多个处理节点
- ✅ 条件路由：根据状态动态决定流程走向
- ✅ 循环控制：支持节点循环执行

## 安装依赖

```bash
pip3 install langgraph langchain langchain-openai langchain-core
```

## 运行应用

```bash
# 进入项目目录
cd ~/Desktop/langgraph-project

# 运行应用
python3 app.py
```

## 工作流说明

应用创建了一个简单的三节点工作流：

1. **初始化节点** (`initialize`)
   - 启动工作流
   - 初始化计数器

2. **处理节点** (`process`)
   - 处理数据
   - 根据计数器决定是否继续循环

3. **完成节点** (`finalize`)
   - 完成工作流
   - 输出最终结果
